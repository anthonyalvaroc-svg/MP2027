# Reportes Fotográficos Site (v5)

Aplicación Web Progresiva (PWA) para organización de reportes fotográficos de mantenimiento preventivo y F17 en campo.

## Características v5:
- Estructura ordenada: `1. F17-CARPETA DE FOTOS`, `2. FORMATOS MP` (Fotos + PDF) y `3. MANTENIMIENTO PREVENTIVO`.
- Conserva el nombre original real de los archivos tomados con Timestamp Camera o subidos desde galería.
- Optimización automática de peso (< 1 MB) para fotos pesadas, excepto la carpeta `15. Vistas de 30° encima de torre cada foto 5MB` que mantiene la resolución original sin pérdida de calidad.
- Compatibilidad con Timestamp Camera Pro y Timestamp Camera Free.
